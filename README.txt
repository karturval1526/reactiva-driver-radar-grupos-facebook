REACTIVA DRIVER — RADAR COMERCIAL PRO V3

Sube index.html, manifest.json y sw.js a la raiz de GitHub Pages.

OBJETIVO:
Encontrar oportunidades comerciales publicas en Facebook y WhatsApp, analizarlas, priorizarlas y registrar prospectos. La publicación final es manual.

FUNCIONES:
- Busquedas especificas de grupos y publicaciones de Facebook.
- Busqueda de grupos/enlaces publicos de WhatsApp y directorios.
- Uber, DiDi, Rappi, inDrive, Yango, Picap y General.
- Analizador de oportunidad 0-100.
- Fabrica de anuncios y respuestas.
- CRM local de prospectos.
- WhatsApp directo a prospectos registrados.
- Plan de prospeccion de 7 dias.
- Exportacion de datos.

NOTA:
GitHub Pages no puede acceder libremente a datos privados de Facebook/WhatsApp. El radar abre busquedas publicas y permite analizar datos visibles que tu encuentres. No automatiza publicaciones, accesos privados ni evasion de restricciones.
