REACTIVA DRIVER COLOMBIA — RADAR DE GRUPOS V1

Uso:
1. Sube index.html a la raíz de un repositorio de GitHub Pages.
2. Activa Settings > Pages > Deploy from branch > main > / (root).
3. Abre la URL desde Android.

Importante:
- Esta versión NO inicia sesión en Facebook.
- NO publica automáticamente.
- Usa una base inicial de grupos/criterios como demostración y genera búsquedas públicas de grupos de Facebook.
- El puntaje es heurístico, no una medición oficial de Facebook.
- Verifica reglas y actividad del grupo antes de publicar.
- Los grupos privados o información no pública no se deben intentar extraer saltando controles de Facebook.
